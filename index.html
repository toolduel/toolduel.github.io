How a duel works

Each episode gives the identical coding prompt to Google's free Gemini tier, a Qwen2.5-Coder 7B model running locally on an RTX 3060, and Claude Code. All three outputs open in the same browser and record for nine seconds.

Measured the same way every time: generation time, lines of code, distinct colours in a frame, pixel-difference motion between frames, and JavaScript errors captured live from the browser console.

On sponsorship

ToolDuel accepts sponsorship, and these are the terms — published here so they can be held against us.

  • A sponsor can buy inclusion in a duel. Their tool gets the same prompt, the same browser, the same instrumentation.
  • A sponsor cannot buy the result. If the tool loses, the video says it lost.
  • Disclosure appears in the video, not buried in a description.
  • Claude Code wrote the measurement harness and also competes. That is disclosed in every episode, and no winner is declared in any comparison it takes part in — including the ones it would win.
